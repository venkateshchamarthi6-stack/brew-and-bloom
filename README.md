# ☕ BREW & BLOOM — Premium Café Website

> **"Slow mornings. Better coffee."**  
> A complete, visually stunning, editorial-grade café website built with modern HTML5, CSS3, and JavaScript for the Web Development Activity project.

---

## 🌿 Overview
**BREW & BLOOM** is inspired by high-end coffee roasters and editorial magazine layouts. It blends warm organic color palettes, subtle typography, and smooth micro-interactions to create a digital sanctuary for coffee lovers.

---

## ✨ Features

- **Editorial Navigation Bar:**
  - Sticky header with frosted glassmorphism effect (`backdrop-filter: blur(12px)`).
  - Clean brand mark with custom SVG iconography and established badge (`EST. 2021`).
  - ScrollSpy active link highlighting.
  - Fully responsive mobile drawer navigation.

- **Asymmetric Hero Section:**
  - Distinctive headline: *"Slow mornings. Better coffee."* with italic serif highlights.
  - Animated pulsing status pill: *"Freshly Brewed Every Day"*.
  - Dual action buttons: *"Explore Our Menu"* & *"Discover Our Story"*.
  - Floating price badge and Head Barista quote cards.
  - Key trust indicators (100% Direct Trade Arabica, 48 hrs Peak Freshness, 4.9★ Community Rating).

- **Continuous Marquee Ticker:**
  - Infinite smooth sliding banner highlighting core artisanal values.

- **About Our Café Section:**
  - Narrative on Chikmagalur shade-grown beans and slow coffee rituals.
  - Editorial dual-image collage with a vintage "SINCE 2021" stamp.
  - Core philosophy pillars: Conscious Philosophy, Fresh Ingredients, Handcrafted Beverages.

- **Interactive Signature Menu:**
  - Dynamic category filters: *All Brews*, *Hot Classics*, *Chilled & Nitro*, *House Signature*.
  - 6 Signature drinks:
    - **Cappuccino** — ₹149 *(Customer Favorite)*
    - **Caffè Latte** — ₹169 *(Swan Latte Art)*
    - **Caramel Macchiato** — ₹189 *(House Signature)*
    - **Cold Brew** — ₹159 *(18-Hour Slow Steeped)*
    - **Mocha** — ₹179 *(Single-Estate Belgian Chocolate)*
    - **Classic Americano** — ₹129 *(Bold Crema Double Shot)*
  - Interactive **"+ Add to Order"** buttons with floating toast alerts.
  - **"View Full Menu"** modal popup displaying the complete café menu.

- **Special Feature Section (Bakery & Crafts):**
  - Showcasing freshly baked croissants, dark chocolate sea-salt brownies, artisan sourdough sandwiches, and manual pour-over stations.

- **Café Experience Gallery:**
  - High-resolution asymmetric photography grid featuring café interiors, barista craft, ceramic mugs, and coffee beans with smooth hover captions.

- **Community Praise & Testimonials:**
  - Clean testimonial cards highlighting genuine customer experiences.

- **Table Reservation & Contact:**
  - Interactive reservation form with auto-filled date and guest count.
  - Complete location details, opening hours, and direct contact inquiry info.

- **Site Footer:**
  - Newsletter subscription with instant feedback.
  - Social media icons and opening hours schedule.

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`).
- **CSS3:** Custom Properties (Variables), Flexbox, CSS Grid, clamp() responsive typography, keyframe animations, responsive media queries.
- **JavaScript (ES6):** Scroll listeners, DOM manipulation, tab filtering, modal management, and form submission simulation.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/venkateshchamarthi6-stack/brew-and-bloom.git
   ```
2. Navigate to the folder:
   ```bash
   cd brew-and-bloom
   ```
3. Open `index.html` in any modern web browser:
   - On Windows: Double-click `index.html` or run `start index.html` in command prompt.
   - On macOS: Run `open index.html` in terminal.
